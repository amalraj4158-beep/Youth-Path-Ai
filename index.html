1

GitHub Account Banao & File Upload Karo

GitHub = teri app ka free storage ghar

1

github.com pe jaao aur account banao

Email aur password se free account. Gmail se bhi sign up kar sakte ho.

🌐 github.com/signup
💡 Tip: Username acha rakh — jaise "yuvapath-app" — yahi teri app ki URL mein dikhega
2

New Repository (folder) banao

Login ke baad "+ New repository" button dabao. Name likho "yuvapath", aur Public select karo. Phir "Create repository" dabao.

github.com/new
Repository name:
yuvapath
✅ Create repository
3

HTML file upload karo

Repository mein jaao → "uploading an existing file" link dabao → apni HTML file drag & drop karo → "Commit changes" dabao.

⚠️ Important: File ka naam index.html rakhna — ye zaroori hai Vercel ke liye!
2

Vercel pe Free Deploy Karo

Live website URL milegi — 2 minute mein

4

vercel.com pe jaao

"Continue with GitHub" se login karo — alag account nahi banana. Vercel seedha GitHub se connect ho jaata hai.

🌐 vercel.com
5

"Import Project" karo

Dashboard mein "Add New → Project" → apna "yuvapath" repository select karo → "Deploy" dabao. Bas! Kuch nahi change karna settings mein.

vercel.com/dashboard
📁 yuvapath 🚀 Deploy
🎉 Result: 2 minute mein teri URL ready ho jaayegi jaise:
https://yuvapath.vercel.app
3

App Info Add Karo (manifest.json)

Phone ko batao — yeh ek proper App hai!

6

GitHub mein ek naya file banao — manifest.json

GitHub pe teri repository kholo → "Add file → Create new file" → naam likho manifest.json → neeche diya content copy-paste karo:

{
  "name": "YuvaPath",
  "short_name": "YuvaPath",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#0D0D0D",
  "theme_color": "#FF6B00",
  "description": "India Youth Career Guide",
  "icons": [{
    "src": "https://via.placeholder.com/512x512/FF6B00/ffffff?text=YP",
    "sizes": "512x512",
    "type": "image/png"
  }]
}
6
💡 Tip: "name" mein apni app ka naam likh sakta hai — YuvaPath ya kuch aur. Phir "Commit changes" dabao.
7

HTML file mein ek line add karo

GitHub mein apni index.html file open karo → Edit (pencil icon) → <head> section mein ye line add karo:

<link rel="manifest" href="/manifest.json">
7

Phir Commit changes dabao. Vercel automatically 1 minute mein update ho jaayega.

4

PWABuilder se APK Download Karo

Yahan se asli Android file milegi — free!

8

PWABuilder website pe jaao

Microsoft ka free tool — specifically isi kaam ke liye bana hai.

🌐 pwabuilder.com
9

Apni Vercel URL daalo

PWABuilder ke search box mein teri URL daal do:

🌐 https://yuvapath.vercel.app

"Start" dabao — yeh teri site analyze karega. Green score aaye toh perfect!

pwabuilder.com
Enter URL of your PWA
https://yuvapath.vercel.app
✅ Start →
10

Android Package select karo aur Download!

Analysis ke baad "Package for stores" button dikha → "Android" select karo → "Generate" dabao → .apk file download ho jaayegi!

pwabuilder.com/reportcard
🍎 iOS 🤖 Android ✓ 🪟 Windows

⬇️ Generate APK
🎉 APK Download ho gayi! Ab is file ko WhatsApp, Telegram, ya Google Drive se share karo. Install hogi seedha phone mein — Play Store ki zaroorat nahi!
11

Phone mein Install Karo (Unknown Sources)

APK install karne ke liye ek setting change karni hogi:


📱 Android Settings → Security → Unknown Sources → ON


Ya phir jab APK open karo toh "Install from unknown source" popup aayega — Allow karo. Sirf ek baar karna hai.

⚠️ Sirf apni khud ki APK install karo — kisi unknown source ki APK kabhi install mat karo phone mein.
